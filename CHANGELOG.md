# Mudanças

## 0.1.0

Abre o gerador de DANFSe no mesmo desenho de repositório das outras calculadoras.

- A suíte do pin é pytest de situação da nota (`stc`) e de texto. O código Go do pin não entra neste git.
- Publica no PyPI no push da `main`, no mesmo run do quality gate, e não no Artifact Registry.
- O `deploy/` vendido deixa os triggers desligados. Quem cria os triggers é a fundação.
- Separa a licença desta lib (`LICENSE`) da licença do pin Go `8d79e6b2` (`LICENSE-RECEITA.md`).
